## A media interface for assistants

RadioTEDU's Agentic Web connects compatible assistants to public station information, now-playing context, programme schedules, podcasts, content search, and studio availability. MCP over Streamable HTTP provides the tool connection; a separate SSE interface carries live broadcast context.

## My role

I created and developed this project, including RadioTEDU's MCP interface. Agentic Web and the MCP connection guide describe parts of the same system.

## Public context and member actions

Public discovery tools can be used without an account. Studio booking is a separate authenticated action with an explicit confirmation workflow. The interface keeps public media discovery separate from broadcast administration.

[Read the MCP connection guide](https://radiotedu.com/mcp) for the endpoint and supported clients. This service belongs to RadioTEDU.

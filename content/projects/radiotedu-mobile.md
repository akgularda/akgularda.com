## Listening across devices

RadioTEDU's mobile project connects stations, podcasts, and community features with background playback and system media controls. Development also covers car, television, casting, and wearable listening contexts.

## My contribution

I contribute to this collaborative project within the RadioTEDU software ecosystem.

## Development status

The public project page describes ongoing development, including Android Auto, Android TV, Google Cast, and Wear OS work. The public mobile release is still listed as coming soon.

[Read the project overview](https://radiotedu.com/technology/projects/mobile/) for the current scope and release information.
